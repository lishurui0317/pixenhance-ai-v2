御·像素 Yupianxiangsu — 使用须知

v1.0.0 · AI 图像超分工具 · 本文档所有性能与故障结论均来自真机实测（测试卡：NVIDIA GeForce RTX 2060 / 6GB 显存 / Windows x64），未实测的配置已明确标注，绝不瞎编。

一、快速上手

  1. 双击桌面图标 Yupianxiangsu 启动（安装程序已自动创建桌面与开始菜单快捷方式）。
  2. 把图片拖进窗口（或点击选择文件）。一次只处理一张图——这是刻意设计：单图模式能把显存峰值压到最低，多图并发只会把你的显卡送走。
  3. 选择目标档位：
    档位输出长边适合场景
    FHD1920 px网页、聊天发送
    2K2560 px普通显示器壁纸
    4K3840 px4K 屏幕、打印（小图会自动跑两遍 AI 放大，耗时最久）

    按长边归一：横图竖图都适用，短边按原比例自动计算。

  4. 点击「开始放大」，等待完成提示即可。输出图会自动打开所在文件夹。
  5. 上次打开的文件夹、档位、模型选择都会被记住，下次启动原样恢复（配置保存在 %LOCALAPPDATA%\Yupianxiangsu\config.json，卸载时可一并清理）。

二、什么配置不能用 / 能用到什么程度

实测结论表（RTX 2060 / 6GB 真机数据）

场景实测结果状态
RTX 2060（6GB 显存）
tile=128 + 单图模式		 正常 GPU 加速。小图 4x 放大约 3.4 秒；4K 级联（两遍 AI 放大）显存峰值约 1.79 GB 完全可用
同一张卡，关闭显存保护
（大 tile / 多图并发）		 显存飙到 5.9 / 6.0 GB，贴着上限裸奔——本应用已默认锁死 tile=128 + 单图，请勿手动改配置文件里的相关参数 默认已规避
无 Vulkan 显卡 / 显卡驱动异常 引擎报 invalid gpu device 后应用自动降级：输出仍能生成，但走的是普通插值放大 + 锐化，没有 AI 细节增强。日志里会写明实际使用的引擎 能用，无 AI
远程桌面 / 虚拟机里的 GPU 会话 远程会话通常拿不到 Vulkan 设备，行为同上（降级保底出图） 能用，无 AI
纯 CPU（完全无显卡） 实测本版本引擎的 CPU 模式（-g -1）直接报 invalid gpu device，不可用；ONNX CPU 保底需要预先转换模型（见第四节第 5 条），当前安装包未内置 → 实际效果同上：普通放大保底 能用，无 AI
显存 2GB 以下的老显卡 未实测，不承诺。tile=128 实测峰值约 1.8GB，理论上勉强够，但出了问题别怪文档没提醒 未实测

关于图片本身的限制（设计行为，不是故障）

  • 原图长边 > 1700 px：再跑 4x 放大收益极低、显存开销极大，应用会自动跳过 AI 直接走插值 + 锐化。想要 AI 效果请喂小图（几百像素的老照片是最佳素材）。
  • 原图超过 100 万像素（约 1200×830 以上）：自动切换切片模式，逐块处理后无缝拼接，耗时相应变长，属正常现象。
  • 支持 JPG / PNG / BMP / WebP 等常见格式；输出统一为 PNG（无损）。

三、报错速查表（真实报错原文 → 解决方法）

报错原文（日志/弹窗出现）原因解决方法
_wfopen ...models/realesrgan-x4plus.param failed Vulkan 模型文件（.param / .bin）缺失——最常见的坑，通常是杀毒软件误删或手动动过 engine\models\ 目录 应用启动时会自动体检并弹窗给出缺失路径。从 github.com/xinntao/Real-ESRGAN/releases 下载 realesrgan-ncnn-vulkan-20220424-windows.zip，把 models 文件夹里的 .param 和 .bin 成对复制回弹窗给出的目录，重启应用。被杀软删了就把安装目录加白名单
invalid gpu device 没有可用的 Vulkan 设备：没装/没更新显卡驱动、远程桌面会话、驱动异常 本机登录并更新显卡驱动后重试；远程桌面里属于预期行为（自动降级保底出图，无 AI 增强）
处理超时（超过 30 分钟） 单张图跑了 30 分钟还没完：图太大 + 档位太高 + 机器太慢三者叠加 换低一档（4K → 2K），或先裁剪再放大。别跟它硬耗
找不到 realesrgan-ncnn-vulkan 可执行文件 安装目录下 engine\realesrgan-ncnn-vulkan.exe 被删或被杀软隔离 杀软加白名单后重装/修复安装；应用内也可手动指定引擎位置
MSVCP140.dll 缺失 / 引擎启动即崩 缺少 Visual C++ 运行库 安装「Microsoft Visual C++ 2015-2022 Redistributable (x64)」，微软官网免费下载
启动日志出现 未在 models/ 找到 ONNX 模型 警告级别，不影响当前使用——只影响"无显卡时的 AI 保底"能力 想启用 CPU AI 保底见第四节第 5 条；不在乎就无视
命令执行成功但未生成超分图片 输出目录不可写（网络盘权限、路径被占用等） 把输出目录换成本地磁盘目录再试

四、进阶说明

1. 引擎自动降级链（实际行为）

Vulkan GPU（AI 增强）→ 失败时 → 普通插值 + USM 锐化 + CLAHE（保底出图）。日志区会用文字注明每张图实际走了哪条路——觉得输出不对劲先看日志，别急着怀疑人生。

2. 显存保护（已内置，无需设置）

  • tile 尺寸锁定 128（实测 400 会吃光 6GB 显存）
  • GPU 任务并发锁定 1（多张图叠加跑 = 显存翻倍暴毙）
  • 单次处理锁定 1 张图，选多张自动只保留一张

3. 4K 档位为什么慢

小图（比如 247×300）到 4K 需要约 16 倍面积提升，应用会连续跑两遍 AI 放大再精修到 3840px——这是"清晰 4K"和"糊成一团的 4K"的区别。慢是 feature，不是 bug。

4. 配置记忆与卸载清理

用户配置存于 %LOCALAPPDATA%\Yupianxiangsu\config.json（安装到 Program Files 后应用目录不可写，这是唯一正确位置）。卸载程序会自动清理该目录。

5. 想要"无显卡也有 AI 增强"？（可选，需要技术动手）

当前安装包未内置 ONNX 模型（仅有 PyTorch 权重）。若需在无 Vulkan 的机器上启用 CPU AI 保底：在有 Python 环境的机器上进入安装目录运行：

pip install torch onnx basicsr → python convert_pth_to_onnx.py

生成 models\realesrgan-x4plus.onnx 后即可自动生效。注意：CPU 跑 Real-ESRGAN 非常慢（小图数分钟起步），纯属"聊胜于无"方案。

五、常见疑问

  • 放大后还是有点糊？ AI 无法凭空捏造不存在的细节，源图信息量决定上限。另外应用刻意避免了"过度锐化出的塑料感"，偏好真实质感。
  • 能一次放大一整个文件夹吗？ 不能，故意的。串行单图是显存安全的唯一解。
  • 处理中能退出吗？ 会弹确认框。强制退出不会损坏源图，但当前这张白跑了。
  • 支持什么系统？ Windows x64（Win10 21H2 及以上推荐，Win11 完美）。32 位系统免谈。
